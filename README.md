# AI 紫微生涯羅盤 — 試用版下載

這裡只放編譯好的 Android 安裝檔（APK）與更新資訊，供研究試用的參與者下載。
**這個 repo 不含原始碼。**

## 安裝

1. 到右邊的 **Releases**，下載最新一版的 `ziwei-life-*.apk`
2. 手機會問要不要允許從瀏覽器安裝應用程式 → 選擇允許
3. 安裝後開啟 App，依畫面指示授權並啟動資料收集

需要 Android 8.0（API 26）以上。

## 更新

安裝之後不需要再回來這裡。App 會自己檢查新版本，有更新時首頁最上面會出現提示，
按下去就會下載並跳出系統的安裝畫面。

**更新不會刪掉已經收集的資料。**

第一次更新時，手機可能會再問一次「允許這個 App 安裝應用程式」，允許之後回到 App
再按一次更新即可。

## 這個 App 會收集什麼

App 使用事件、活動辨識訊號與螢幕開關事件，全部只保存在你自己的手機上。
詳細說明與刪除方式在 App 內的「設定 → 資料與隱私」。

內建的 AI 對話預設關閉；啟用後，提問時才會送出一份去識別化的行為摘要，
不含 App 名稱、原始事件或個人資料。同意可以隨時撤回。

## 問題回報

請直接聯繫研究負責人，並附上「設定 → 版本與更新」顯示的版本號。
