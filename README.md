# AI 紫微生涯羅盤 — 試用版下載

這裡只放編譯好的 Android 安裝檔（APK）與更新資訊，供研究試用的參與者下載。
**這個 repo 不含原始碼。**

需要 Android 8.0（API 26）以上。

## 安裝

1. 用手機開啟右邊的 **Releases**，下載最新一版的 `ziwei-life-*.apk`
2. 手機會問要不要允許從瀏覽器安裝應用程式 → 選擇**允許**
3. 安裝時 Google Play 可能跳出「**建議掃描應用程式**」→ 按 **掃描應用程式**，
   等幾秒掃完就會繼續安裝
4. 安裝後開啟 App，依畫面指示授權並按「啟動收集」

> 為什麼會被攔：這個 App 沒有上架 Google Play，所以 Play 安全防護沒看過它。
> 讓它掃是最省事的做法，掃完就會放行。

## 更新

安裝之後不需要再回到這個頁面。App 會自己檢查新版本，有更新時首頁最上面會出現提示，
按「下載並更新」就會下載並跳出系統的安裝畫面。

**更新不會刪掉已經收集的資料。**

第一次更新時，手機會多問一次「**允許這個 App 安裝應用程式**」：

1. 按下去會跳到系統設定 → 把開關打開
2. 按返回鍵回到 App
3. 再按一次「下載並更新」

之後的更新就不會再問了。

## 這個 App 會收集什麼

App 使用事件、活動辨識訊號與螢幕開關事件，全部只保存在你自己的手機上。
詳細說明與刪除方式在 App 內的「設定 → 資料刪除」。

內建的 AI 對話預設關閉；啟用後，提問時才會送出一份去識別化的行為摘要，
不含 App 名稱、原始事件或個人資料。同意可以隨時撤回。

## 問題回報

請向發給你這個連結的人詢問，並附上「設定 → 版本與更新」顯示的版本號。

## 試用結束後

在 App 內開啟「設定 → 資料匯出」，勾選要交出哪幾種資料，按下按鈕後
由你自己選擇要用什麼方式傳送。沒有勾選的資料不會被讀取，也不會出現在檔案裡。
